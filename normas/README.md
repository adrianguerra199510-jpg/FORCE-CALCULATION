# Normas de referencia

Carpeta para los documentos normativos que usa la aplicación de cálculo de cargas de viento y sismo.

Subir aquí:

- Capítulo de **cargas de viento** del REP-2021
- Capítulo de **cargas sísmicas** del REP-2021
- `REP-2014 MAPAS.pdf` (mapas sísmicos)
- Cualquier tabla o anexo con valores por provincia/distrito (Ss, S1, velocidad básica de viento)

> Nota: para la primera versión los documentos se leyeron desde los vínculos de OneDrive
> (REP-2021, REP-2014 MAPAS y ASCE 7-05), por lo que no fue necesario subirlos aquí.
